Creating a ZCB Term Structure

A continuously compounded zero-coupon curve fitted to every US Treasury note and bond quoted in the Wall Street Journal, using the Svensson functional form, so that each Treasury payment date has a discount rate r(t) and discount factor d(t) = e−r(t)t. Implemented in Python and Excel; both reproduce the same numbers.

Fitted model

Svensson (1994) zero curve, estimated by least squares on first-order yield errors (price error divided by dirty price times modified duration). Nelson-Siegel is the nested four-parameter benchmark.

r(t) = β₀ + β₁·(1−e−t/τ₁)/(t/τ₁) + β₂·[(1−e−t/τ₁)/(t/τ₁) − e−t/τ₁] + β₃·[(1−e−t/τ₂)/(t/τ₂) − e−t/τ₂]    d(t) = e−r(t)·t
